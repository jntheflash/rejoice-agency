# Brouillons d'articles

Les brouillons rédigés par `/nouvel-article` atterrissent ici, le temps d'être relus et validés.
Une fois validés, `/publier` les déplace vers `ressources/` et met tout le site à jour
(carte, compteurs, sitemap, redirections, llms.txt, maillage). Ce dossier ne contient donc
normalement que des articles en attente de validation.
